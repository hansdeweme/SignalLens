## Explicit gaps and audit limits

UI-6 adds these authoritative presentation/export boundaries without duplicating the lifecycle owners above:

| Requirement | UI-6 owner | Existing coverage reused |
|---|---|---|
| Recorded metadata trust/value/filter and stored recovery | test_provenance_reporting::{test_recorded_fields_preserve_original_value_and_unverified_association,test_metadata_unavailable_execution_does_not_become_missing_provenance,test_metadata_filter_excludes_nonmatches_and_binary_detail_is_descriptive,test_stored_metadata_recovery_requires_both_run_identity_and_source_hash} | Metadata classification/provenance/verification semantics remain in reasoning/confidence contracts |
| Visible contextual source and revision | test_provenance_reporting::test_osint_workspace_displays_committed_source_and_revision | Existing annotation commit/cancel/save-failure/dialog-switch owners remain unchanged |
| Preview/export contract and asynchronous request | test_provenance_reporting::{test_preview_export_bytes_share_snapshot_and_legacy_text_fallback,test_background_export_uses_captured_snapshot_off_gui_thread,test_obsolete_preview_and_late_export_cannot_become_current,test_background_export_failure_never_reports_saved} | Existing run-report atomic publication, stale session and report retry tests remain unchanged |
| Provenance field and annotation-aware navigation | test_provenance_reporting::test_provenance_navigation_checks_annotation_revision_and_recorded_field_link | UI-5 forensic result identity/navigation checks remain authoritative |

- Native Windows DPI, multiple monitors and real mouse/drag feel are not established by offscreen Qt tests.
- Two synthetic/reference-derived cases are not an empirical forensic benchmark. Full private-image pipelines were not rerun for this test-only change.
- A complete persisted historical lineage graph is optional. Static registry relationships must remain distinguished from run measurements.
- Automated similarity candidates are not a complete semantic overlap proof. Remaining old narrative/renderer checks can be reviewed later with concrete defect evidence.
- Shared fixtures do not authorize shared mutable session/results. The QApplication is session-scoped; windows, settings, sources and projection data remain function-scoped.
