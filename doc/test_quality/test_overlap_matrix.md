## Removal evidence

The removed C1/C2 function bodies are represented by baseline.json's original node IDs, calls and full assertion lists; current retained assertions can be compared in final.json and source. C3/C4 remove individual parameter inputs, not whole behavioral groups. See fault_injection_results.json and tools/check_test_retention.py: isolated in-memory faults for reversed-order policy, repeated evaluation, card mutation, empty-input polarity and digitalCapture enhancement are detected by the retained groups. A sixth probe confirms strengthened detector-filter coverage. These targeted probes establish concrete detection examples, not a complete mutation score or proof against every future defect.

Accounting: remove 6 old collected cases (2 + 2 + 1 + 1), add 1 parameter instance to an existing stronger group, net −5. All other cases remain; numeric-display and benign-result parameter IDs change for clarity without dropping input values.
