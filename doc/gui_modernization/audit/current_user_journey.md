Interaction counts are control activations; file chooser typing, reading, scrolling and external application actions are variable and excluded where stated. ## Cross-screen consistency and discovery

The only tabs belong to Settings; investigation navigation is a long report plus Tools menu and external folders. There is no implemented sequence Overview → Detector → Evidence Explorer. Do not describe those proposed sections as existing functionality. Text controls allow native selection/copy; long paths remain in a read-only line edit. There is no explicit global keyboard command set, recent-run reopening or persisted workspace layout.

## Top journey interventions

Pin source identity, run state, primary hypothesis, confidence and limitations together. Separate input configuration from result inspection. Move OSINT into an attributed provenance workspace. Make every detector accessible through a named artifact entry and availability reason. Preserve one run snapshot while navigating and while producing reports; selecting a new image must invalidate old trace access atomically.

These proposals reduce view-to-view memory demands. Interaction targets for future acceptance: open any detector in at most two in-app activations; reach policy rationale from overview in one; keyboard selection of evidence reveals its explanation without a second window. These are design targets, not claims about current performance.
