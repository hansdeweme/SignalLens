# Visual validation

capture_validation.py generated the screenshots and capture_manifest.json using Qt's offscreen renderer on Windows with installed Segoe UI fonts and DPR 1.0. These are widget captures, not native Windows desktop screenshots. Normal 1280×900, minimum 1040×720 and expanded logical 1920×1080 layouts were exercised. The maximized-state capture is limited to 796×796 by the offscreen virtual screen and is below the supported minimum width; it is retained as a platform limitation, not accepted native maximization validation. Physical DPI scales, multi-monitor placement and native mouse/drag behavior remain unverified, including the inherited UI-4 DPI review.

Captures cover empty Evidence, both references' grouped/scoped evidence, supporting/moderating details, processing-lineage context, hypothesis summary, ordered routes, corroboration, final confidence policy, base contributions, operation/reconciliation records and minimum size. Contradicting evidence, missing lineage, confirmed numerical duplicate suppression and narrative-only legacy states use clearly labeled UI-only fixtures because the two production references do not exercise every case. No stored result/image was altered for a fixture.

Inspected the minimum Evidence table, lineage view, contribution ledger and Midjourney confidence view. Tables retain readable headers/selection, fixed column widths with horizontal scrolling at narrow sizes, vertical scrolling for long descriptions, and copyable exact details. Five filters use native controls. Observation, interpretation and scoped role remain separated. Structured lists render as readable lines; raw JSON is available only through explicit technical/raw access. The existing theme tokens cover table headers and focus. No decorative relationship graph or probability display was added.

Tables and detail panes use adjustable splitters. At minimum size fewer rows are visible, with all columns and details reachable by native scrolling. This is a bounded inspection workspace, not a claim that the entire reasoning trace fits simultaneously on a small screen. Native Windows/DPI review remains an explicit acceptance limitation.
